# 覆盖率问题总结和解决方案

## 🔍 关键发现

### 1. 单帧覆盖率低是**正常现象**

测试结果显示 `scene0000_00` 的覆盖率：
- **最小**: 1.6%
- **最大**: 6.8%
- **平均**: 4.4%

**原因**: 
- 单个相机视角只能看到场景的一部分
- 3D 点云包含整个场景的所有点
- 需要**多视角融合**才能覆盖所有点

### 2. OpenScene 的做法

OpenScene 并不期望单帧有高覆盖率，而是：

#### 训练时 (`data_loader.py`):
```python
# 循环尝试多帧，找到"足够好"的帧
while True:
    # 计算投影
    single_mapping = self.point2img_mapper.compute_mapping(pose, locs_in, depth)
    mask = single_mapping[:, 2]
    
    # 检查可见点数 (不是覆盖率!)
    if np.sum(mask) > 400 and np.sum(mask) < 65000:
        break  # ✅ 找到有 400+ 可见点的帧就够了
```

**关键**: 
- 不要求高覆盖率 (30-60%)
- 只要求**绝对点数** > 400 (足够训练)
- 每个 batch 看到不同的点，多个 batch 累积起来覆盖全场景

#### 推理时 (多视角融合):
```python
# 遍历所有帧，融合特征
for img_dir in img_dirs:
    # 计算投影
    mapping = compute_mapping(pose, coords, depth)
    
    # 累积每个点的特征
    for point_idx in visible_points:
        features[point_idx] += extracted_feature
        counts[point_idx] += 1

# 平均
features = features / counts
```

**关键**: 多帧融合后覆盖率接近 100%

## ✅ 正确的理解

### 覆盖率的含义

1. **单帧覆盖率** (4-7%): 
   - 一个视角能看到的点占总点数的比例
   - **低是正常的**，因为相机视野有限

2. **训练所需点数** (400+):
   - 不看覆盖率，只看绝对数量
   - 400 个点足够计算 loss 和梯度

3. **多帧融合覆盖率** (接近 100%):
   - 所有视角累积后的覆盖率
   - 用于推理和评估

### 为什么训练不需要高覆盖率？

```python
# 每个 batch 看到不同的点
Batch 1: 场景 A 的 400 个点 (视角 1)
Batch 2: 场景 A 的 450 个点 (视角 2)  # 不同的点!
Batch 3: 场景 B 的 500 个点 (视角 1)
...

# 多个 epoch 后，所有点都被训练过多次
Epoch 1: 场景 A 的点集 P1
Epoch 2: 场景 A 的点集 P2  # 随机选帧，不同的点
Epoch 3: 场景 A 的点集 P3
...
```

**关键**: 
- 每次随机选帧，看到不同的点
- 多个 epoch 累积，覆盖所有点
- 类似随机梯度下降 (SGD) 的思想
