## 修改说明

### 主要变更

1. **`_load_3d_simple()` 函数**:
   - 添加参数 `data_2d_root` 和 `enable_runtime_projection`
   - 当 `x_label/y_label` 缺失时,尝试运行时计算投影
   - 计算逻辑参考 `data_loader.py` 的实现

2. **`OpenVocabScannetDatasetV2` 类**:
   - 在 `__init__` 中读取 `data_2d_root` 配置
   - 在 `__getitem__` 中传递 `data_2d_root` 给 `_load_3d_simple()`

### 运行时投影计算逻辑

```python
# 1. 查找场景的 2D 数据目录
scene_2d_dir = data_2d_root / scene_name

# 2. 获取图像列表,选择中间帧
img_dirs = sorted(glob(str(scene_2d_dir / "color" / "*")))
img_dir = img_dirs[len(img_dirs) // 2]

# 3. 读取相机位姿和深度图
pose = np.loadtxt(pose_path)
depth = imageio.imread(depth_path) / 1000.0

# 4. 计算 3D 到 2D 的投影映射
mapper = getMapping()
single_mapping = mapper.compute_mapping(pose, locs, depth)

# 5. 提取有效的 x_label 和 y_label
zero_rows = np.all(single_mapping != 0, axis=1)
valid_indices = np.where(zero_rows)[0]
x_label[valid_indices] = single_mapping[valid_indices, 0]
y_label[valid_indices] = single_mapping[valid_indices, 1]
```

## 性能影响

### 运行时投影计算的开销

每个样本需要:
1. 读取图像路径列表: ~1-5ms
2. 读取位姿文件: ~1-2ms
3. 读取深度图: ~10-20ms
4. 计算投影映射: ~50-100ms
5. 提取有效投影: ~5-10ms

**总计**: 约 70-140ms/样本

### 对训练速度的影响

假设:
- Batch size = 2
- 每个 epoch = 500 batches
- 原始速度: 1.0s/batch

增加运行时投影后:
- 新增开销: 0.14s * 2 = 0.28s/batch
- 新速度: 1.28s/batch
- **速度下降约 28%**

### 优化建议

1. **缓存投影结果**:
   - 第一次计算后缓存到内存
   - 后续 epoch 直接使用缓存
   - 可节省 90%+ 的时间

2. **预计算投影标签**(长期方案):
   - 使用 `tools/generate_projection_labels.py`
   - 一次生成,永久使用
   - 训练速度不受影响

## 配置选项

### 禁用运行时投影

如果想禁用运行时投影(使用零标签):

```python
# 在 dataset/open_vocab_dataset_v2.py 中
class OpenVocabScannetDatasetV2(torch.utils.data.Dataset):
    def __init__(self, config: OpenVocabDatasetV2Config):
        # ...
        self.enable_runtime_projection = False  # 改为 False
```

### 通过配置文件控制

可以在 `OpenVocabDatasetV2Config` 中添加配置项:

```python
@dataclass
class OpenVocabDatasetV2Config:
    # ... 现有配置 ...
    enable_runtime_projection: bool = True  # 新增
```

然后在 YAML 配置中:

```yaml
dataset:
  enable_runtime_projection: true  # 或 false
```

## 常见问题

### Q1: 为什么选择中间帧?

**A**: 中间帧通常:
- 相机位置较好
- 点云覆盖率较高
- 投影质量较好

也可以修改为:
- 随机选择: `img_dir = random.choice(img_dirs)`
- 选择投影点最多的帧(需要遍历所有帧,更慢)

### Q2: 投影覆盖率低怎么办?

**A**: 如果投影覆盖率 < 30%:
- 检查相机参数是否正确
- 检查深度图质量
- 尝试其他帧
- 考虑使用多帧融合

### Q3: 内存占用会增加吗?

**A**: 会略微增加:
- 深度图: ~640x480x4 = 1.2MB/样本
- 投影映射: ~N_points x 3 x 8 = 约 2MB/样本
- 总计: 约 3-5MB/样本

如果 batch_size=2, 增加约 6-10MB。

### Q4: 可以并行计算吗?

**A**: 可以,但需要修改:
- DataLoader 的 `num_workers > 0`
- 每个 worker 独立计算投影
- 注意 `getMapping()` 的线程安全性

- **短期**: 使用此修复快速开始训练
- **长期**: 预先生成包含投影标签的数据文件
