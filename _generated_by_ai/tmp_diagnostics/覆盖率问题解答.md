## 📊 覆盖率的含义

### 分母是什么？

```
覆盖率 = 有 2D 投影的 3D 点数 / 场景中所有 3D 点数

例如 scene0000_00:
- 分母: 81,369 个 3D 点（场景中的所有点）
- 单帧可见: 5,555 个 → 覆盖率 = 5,555 / 81,369 = 6.8%
- 多帧融合: 77,681 个 → 覆盖率 = 77,681 / 81,369 = 95.5%
```

**分母 = 场景中的所有 3D 点**

---

## 🎯 两种思路对比

### 思路 1: 多帧融合（预处理）

**目标**：让每个 3D 点都有 2D 特征

**方法**：
```
预处理阶段（一次性）:
  遍历所有 279 帧
  ↓
  每个 3D 点累积多帧的 2D 特征
  ↓
  平均融合
  ↓
  保存融合特征（95% 的点有特征）

训练阶段:
  加载融合特征 → 直接训练
```

**效果**：
- ✅ 95% 的点有 2D 特征
- ✅ 训练时所有点都可用
- ✅ 特征质量高（多帧平均）

**代价**：
- ❌ 需要预处理时间（~3秒/场景）
- ❌ 需要存储空间

---

### 思路 2: 单帧 + 过滤（运行时）⭐ OpenScene 训练用这个

**目标**：每次训练只用部分可见点，但多次累积覆盖所有点

**方法**：
```
训练阶段（每次）:
  随机选一帧
  ↓
  计算投影（5-10% 的点可见）
  ↓
  只保留可见的点（400-65000个）
  ↓
  只用这些点训练
  ↓
  下一个 batch 换一帧
  ↓
  多个 batch/epoch 后累积覆盖所有点
```

**效果**：
- ✅ 不需要预处理
- ✅ 每个点都有有效的 2D 对应（100%）
- ✅ 多样性好（每次看不同的点）

**代价**：
- ⚠️ 每次只用 5-10% 的点
- ⚠️ 需要更多 epoch 才能覆盖所有点
