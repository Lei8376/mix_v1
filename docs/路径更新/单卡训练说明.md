# 单卡训练指南

## ✅ 配置已调整为单卡优化

配置文件 `config/train_scannet_v2_full_multi_gpu.yaml` 已针对单卡环境优化：

### 调整内容

1. **Batch Size**: 16 → 8
   - 降低显存占用
   - 如果显存充足（24GB+）可以改回 16
   - 如果显存不足可以改为 4 或 2

2. **Num Workers**: 12 → 8
   - 适配单卡 CPU 负载
   - 可根据 CPU 核心数调整

3. **Resume 路径**: 已注释掉
   - 默认从头开始训练

```yaml

  batch_size: 4  # 或者 2
```

### 恢复训练

如果训练中断，可以恢复：

1. 找到最后一个 checkpoint
```bash
ls -lt checkpoints/full.4/
```

2. 编辑配置文件，取消注释 resume 行：
```yaml
trainer:
  resume: checkpoints/full.4/checkpoint_epoch_XX.pth
```

3. 重新运行训练命令

### 常见问题

**Q: 训练速度慢怎么办？**
- 增加 `num_workers`（4 → 8 → 12）
- 检查是否使用了 SSD 硬盘
- 确认预计算特征已生成

**Q: 显存 OOM 怎么办？**
- 降低 `batch_size`（8 → 4 → 2）
- 增加 `gradient_accumulation_steps`（2 → 4）
- 使用更小的模型（编辑 model 配置）

**Q: Loss 不下降怎么办？**
- 检查学习率（当前 5e-5）
- 查看 TensorBoard 曲线
- 确认数据路径正确
