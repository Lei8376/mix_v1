使用你提供的命令：

## 常见问题

### Q: 如何恢复训练？
在配置文件中取消注释 `resume` 行：
```yaml
trainer:
  resume: checkpoints/full.4/checkpoint_epoch_17.pth
```

### Q: 显存不足怎么办？
1. 减小 batch_size（在配置文件中）
2. 使用梯度累积（已配置）
3. 使用更小的模型架构

### Q: 如何评估模型？
```bash
python eval_mix_model.py \
    --checkpoint checkpoints/full.4/best_model.pth
```
